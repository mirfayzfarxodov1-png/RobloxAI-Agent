## Quruvchi V3 Workbench

V3 adds a deterministic API-keyless architecture planner, a connected Studio build spec, heuristic multi-pass Luau/performance/security audit, QA matrix and parametric model specification. All V3 API requests require a signed-in session and are rate-limited. Static findings are heuristics, not proof of correctness. QA remains not-run until Studio tests happen. A model spec is not a mesh file. The build prompt requires inspecting the existing Studio tree and forbids claiming unconfirmed changes or Play-test success.
